# go-argo-mcp v0.2.1

This release corrects workflow filtering and pagination.

- Workflow lists request accurate continuation from Argo, including when more live workflows exist but the archive is empty.
- Phase filters run in Argo before page limits apply. Failed workflows no longer disappear when newer workflows have other phases.
- CronWorkflow history uses the same continuation correction.

Homebrew publication now includes a macOS cask that installs release binaries without Xcode. Linux installations continue to use the formula.

The tool API and read-only defaults are unchanged. Workflow logs still read live pods only. Artifact tools return download links without downloading their contents.
