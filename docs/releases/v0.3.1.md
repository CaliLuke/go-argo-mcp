# v0.3.1

This patch updates runtime dependencies and regenerates the MCP bindings. Logging now uses the unified OpenTelemetry APIs. Building from source requires Go 1.27.2.

The 30-tool catalog, environment configuration, read-only defaults, and destructive-action confirmation requirements are unchanged.

Upgrade on macOS with:

```sh
brew update
brew upgrade --cask CaliLuke/tap/go-argo-mcp
```

Restart the MCP server after upgrading.
